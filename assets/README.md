# Provider logos

Claude and OpenAI/ChatGPT marks identify the corresponding services. Trademarks belong to Anthropic and OpenAI; this personal dashboard is not affiliated with either company.

SVG sources from [Lobe Icons](https://github.com/lobehub/lobe-icons):
- [Claude color](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/claude-color.svg)
- [OpenAI](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/openai.svg)

Source SVGs are preserved. Bundled 44 px PNGs are rasterized at 192 px with librsvg (for correct SVG even-odd fills) and downsampled with Pygame; the monochrome ChatGPT mark uses white for the dark background. No asset downloads occur at runtime.

[OpenAI brand guidelines](https://openai.com/brand/).

The Lobe Icons source license is preserved in [LICENSE.lobe-icons](LICENSE.lobe-icons).
